# Laboratorul 2 – Comunicația inter-proces

Fiecare exercițiu este într-un fișier Go separat și poate fi rulat independent:

```bash
go run exercise1.go
go run exercise2.go
go run exercise3.go
go run exercise4.go
go run exercise5.go
go run exercise6.go
go run exercise7.go
```

Exercițiile folosesc goroutines și channels, conform temelor din laborator.
Exercițiul 6 simulează timpi de cursă aleatori. Exercițiul 7 folosește două
trasee exemplificative, deoarece enunțul nu fixează coordonate concrete.
